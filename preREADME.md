# Work Experience Prerequisites
## 2-Day Data Science & Data Engineering Taster 🧱

To take part in the **Bricktastic DataOps Taster** experience, candidates should have the following ready **before arrival**.

---

## Checklist

### An email address
Required for GitHub sign-up. Use an email you plan to keep long-term, because your GitHub account will become the place where you build your coding and data portfolio over time.

### A laptop that can access GitHub Codespaces
Must be able to open **https://github.com** in a modern browser (Chrome or Edge recommended).
> No installation needed — everything runs in the browser via GitHub Codespaces.

### A GitHub account
Students will use GitHub Codespaces to run the starter repository:
**nicoldotyap/bricktastic_dataops_taster**

Sign up at: https://github.com/signup

> Have a working email for registering.

### Basic digital literacy
You should be comfortable with:
- Navigating browser tabs
- Following step-by-step written instructions
- Typing commands into a terminal

> No prior coding or data experience required — we'll teach you everything on the day.

### Access to GitHub onsite
Check that you can access the following site on your school or work Wi-Fi:
- https://github.com

> If GitHub is blocked, ask IT to unblock it before the session.

### Optional: Headphones
Useful for focus during independent work blocks.

### Curiosity and willingness to explore 🔍
The most important prerequisite. Come ready to ask questions and try things out — getting stuck is part of the process!
