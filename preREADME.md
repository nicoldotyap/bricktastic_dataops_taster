# Work Experience Prerequisites
## 2-Day Data Science & Data Engineering Taster 🧱

To take part in the **Bricktastic DataOps Taster** experience, candidates should have the following ready **before arrival*.

---

## Checklist

### An email address
Required for GitHub and Kaggle sign-ups.Use an email you plan to keep long‑term, because your GitHub account will become the place where you build your coding and data portfolio over time

### A laptop that can access VS Code Web
Must be able to open **https://vscode.dev** in a modern browser (Chrome or Edge recommended).
> No installation needed — everything runs in the browser.

### A GitHub account
Students will be granted read access to clone the starter repository:
**nicoldotyap/bricktastic_dataops_taster**

Sign up at: https://github.com/signup

> Have a working email for registering.

### A Kaggle account
Needed to access the dataset used in the project.

Sign up at: https://www.kaggle.com

> Use the same email as your GitHub account to keep things simple.

### Basic digital literacy
You should be comfortable with:
- Downloading and uploading files
- Navigating browser tabs
- Following step-by-step written instructions

> No prior coding or data experience required — we'll teach you everything on the day.

### School network access to GitHub and Kaggle
Please check with your IT department that these sites are **not blocked** on school Wi-Fi before arriving:
- https://github.com
- https://kaggle.com
- https://vscode.dev

### Optional: Headphones
Useful for focus during independent work blocks.

### Curiosity and willingness to explore 🔍
The most important prerequisite. Come ready to ask questions and try things out — getting stuck is part of the process!
